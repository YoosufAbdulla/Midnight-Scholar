Patch Notes
What's new in Midnight Scholar
v2.9 Apr 2026
Accounting spec rewrite — replaced the generic placeholder with the full Pearson Edexcel IAL Accounting specification (Issue 2). U1 (WAC11) covers all six topics from Principles of accounting through Social and ethical accounting; U2 (WAC12) covers all nine topics from Limited companies through ICT in accounting. Every objective is tagged with its official sub-code (e.g. 1.3.12, 2.6.1).
Accounting past papers — 44 new entries in the catalogue, covering every Jan, May/Jun and Oct session from Jan 2019 through Jan 2026 for both WAC11 and WAC12. Correct max of 200 marks per unit.
Add Paper combo fix — previously, users whose first subject in the dropdown wasn't "math" (e.g. business-stream users with bus/econ/acc) would get zero matches when searching for subjects further down their list. The subject chip filter now only locks when the user explicitly changes the Subject select, not on the default first-option value.
Max-marks autofill — picking a subject from the dropdown now pre-fills the max-marks field with that subject's typical value (200 for accounting, 80 for business/economics, 75 for math, etc.), derived from the catalogue. No more accounting papers silently saved as 75-mark attempts.
Accounting unit set — Custom unit selector now shows WAC11 (U1) and WAC12 (U2) pills correctly for accounting; AS set shows U1 only, A2 set shows U2 only.
Spec RAG auto-collapse fix — expanded units no longer snap shut a few seconds after opening. The cloud-sync listener was rebuilding the Spec RAG HTML on every push (including idle round-trips of your own saves), and accordion open-state lived only in the DOM. The listener now diffs the incoming snapshot and skips the rerender when nothing changed, and when spec data does change it preserves the open sections and scroll position across the rerender — matching the pattern already used for RAG clicks. Same fix applied to note save and delete.
Cloud hydration consolidation — four code paths (local load, cloud load, real-time sync, and Drive restore) each had their own copy of the "ensure every required field exists + hydrate SPEC topics" logic, and they had drifted. Two of them only hydrated science subjects, silently stripping Accounting/Business/Economics topics from business-stream users' state on restore or after cross-device sync. Now all four go through a single hydrateState() helper that uses activeSubjects() and covers every subject.
Drive error-handling — Drive API calls now throw on every non-2xx response, not just 401. Previously 403/404/5xx errors were silently returned as success, so backupToDrive could bump the "last backed up" timestamp even when the upload actually failed. Upsert now also sends the blob with its correct Content-Type instead of always claiming application/json.
Snapshot prune resilience — when saving a manual snapshot, a single failed DELETE during old-file cleanup no longer makes the whole save appear to fail. The upload success is reported; prune errors are logged but non-fatal.
Sync clock-skew guard widened — the self-echo rejection window in the real-time listener went from 2 seconds to 10, comfortably covering typical mobile clock skew. Legitimate cross-device pushes arriving within seconds of your own write no longer get rejected.
Sync debounce max-wait — continuous rapid interaction (e.g. typing in a notes textarea that saves on every keystroke) could previously defer cloud sync indefinitely. A 15-second max-wait now guarantees sync fires even during sustained activity.
Maths textbook exercises — new Objectives/Exercises toggle on the Maths tab of Spec RAG. Switch to Exercises mode and every topic shows the textbook exercises that practise it (e.g. "1A Indices", "2D Inverse functions", "Chapter review 6"), each with its own RAG dot. All 7 Pearson IAL Maths books populated: P1-P4 plus M1, S1, D1 — 56 topic groups, 305 exercise rows. Exercise RAG is independent of topic RAG (topic rates your understanding; exercise rates your practice), decays the same way as topic RAG (green fades to amber after 14 days, amber to red after 21), and syncs across devices just like everything else. Only appears for Mathematics; the toggle hides on other subjects.
Hold-for-green on exercise dots — exercise RAG dots missed the hold-to-set-green gesture that topic dots have. Now matches topic behaviour: short tap cycles unset → red → amber → green → unset; 600ms hold jumps straight to green.
Topbar mini-nav fix — on desktop, opening Spec RAG used to underline every subject in the topbar (Math + Bio + Phys + Chem all at once) because the nav activator matched every .mtab with data-page="spec". Now only the currently-active subject's pill is underlined, and switching sub-tabs updates the topbar in sync.
Onboarding ticks off instantly — the "log your first session", "add a past paper" etc. tasks used to have a noticeable delay before showing their ✓, because the widget only refreshed when some unrelated code path happened to call renderOnboarding(). Now hooked into save() directly so any state change updates the widget on the next frame.
Home quote card redesign — the quote card on the home page has been rebuilt in an editorial pull-quote style: category + rotation number at the top ("Philosophy · No. 47"), serif body in one consistent size, understated mono author at the bottom. The old dynamic font-sizing system (which measured the card, counted characters, and scaled fonts to fit) has been removed — it was ~60 lines of fragile measurement code and made short quotes artificially dramatic. Existing | markers in quotes now style the clause after the pipe as italic muted serif, which the editorial layout uses for emphasis. Visually calmer, more consistent across quote lengths, ~50 lines of code deleted.
Quote card: minimal redesign + curated pool — the quote card has been simplified again to a Xan Oku-style minimal layout: serif body, uppercase mono author with wide letter-spacing, no category/number label. The pool itself has been curated from 45 quotes down to 33: dropped the overlong and the misattributed (Quality is not an act, If you can't measure it, the Adam Smith butcher passage), dropped corporate filler (Drucker's management lines, Hayek), and added a new Proverb category with eight short universal lines — Fall seven times stand up eight, Journey of a thousand miles, Rome was not built in a day, Slow and steady wins the race, and more. Existing users with the old pool saved locally are auto-migrated to the curated list on next load; any custom quotes they added are preserved.
Quote card header + final curation — the home quote card now has a REFLECTION header bar matching the NEXT EXAM card's structure, with a quiet "click to cycle" hint on the right. This fixes the orphaned feeling the minimal card had on wide screens. The quote pool has been trimmed again (33 → 27) with a stricter "does this land at 1am during revision?" filter: dropped the anger-control hadith, Know thyself, Warren Buffett, Steve Jobs, Keynes, and a few clichéd proverbs. Added four Arabic proverbs in English: Patience is the key to relief, Repetition teaches even the slowest learner, If speech is silver, silence is golden, Time is like a sword — if you do not cut it, it cuts you.
Profile setup: refined and gated — the profile setup modal now has a three-dot step indicator at the top (done / active / pending), personalises step 2 with the user's name ("Nice to meet you, Saif"), and has softer reassuring copy ("you can change this later" on subjects). More importantly, the gate is now unbreakable: nav() refuses to change pages until the profile is complete, URL hash changes are blocked, and the modal has no ESC or click-outside dismiss. Users must complete setup before reaching any part of the app — there is no "empty state" limbo they can get stuck in.
Onboarding tasks are now specific — "Rate some topics" is now "Rate 5 topics" with a live X / 5 rated progress hint so you can watch your progress count up. "Add a past paper attempt" is now "Log a past paper with a score", and the hint distinguishes between papers you've added but not scored yet ("1 added — add a score") vs papers you've completed ("1 scored ✓"). No more guessing what completes the task.

Guide
Get the most out of Midnight Scholar
Spec RAG Past Papers Sessions Analytics Notes Tools Data & Sync
Spec RAG
Rate every topic Red, Amber, or Green so you always know what needs attention. This is the core of Midnight Scholar — everything else feeds from it.
1
Pick a subject from the tabs at the top. Each tab shows your overall RAG progress at a glance.
2
Tap a dot to cycle it — unrated → Red → Amber → Green. Hold for 0.6s to jump straight to Green.
3
Dots fade over time if you don't revisit them. A fading dot is a reminder — tap it to reset the clock.
4
Expand any topic to read the exact spec objectives. Know precisely what the examiner expects.
tip Use Mark All Green on a unit header after a solid revision session — bulk-rate a whole section in one tap.
Past Papers
Track every paper you attempt — scores, grades, trends, and weaknesses. Three views let you see your progress differently.
1
Hit + Paper and log your subject, unit, year, session, max marks, and score.
2
Add a weakness note — a short phrase for what went wrong. These feed the Weak Topics page automatically.
3
Switch between List ☰, Rings ◎, and Wall ⊞ views to see your attempts from different angles.
4
Use ⚑ flag on individual questions to mark ones you want to revisit — they appear in Weak Topics.
tip Log papers even when you do badly. Analytics needs data points — a poor score is more useful logged than unlogged.
Study Sessions
Log every revision session to build a picture of how you spend your time. The streak keeps you consistent.
1
Hit + Session in the topbar after any revision session. Log the date, subjects, and hours.
2
Your streak counter increments every day you log at least one session. Don't break the chain.
3
The weekly chart on the home page shows how your study hours are distributed across subjects.
4
Add a session note to record what you actually covered — useful for reviewing the week.
tip Use the Pomodoro timer (clock icon in topbar) to structure your sessions — 25 min focus, 5 min break.
Analytics & Heatmap
See your score trends, averages, and RAG distribution across subjects. Use this to decide what to focus on next.
1
The score trend chart shows how your paper marks change over time per unit — spot plateaus and improvements.
2
The RAG distribution bar shows your overall spec coverage — aim to shift Red and Amber to Green before exams.
3
The Weak Topics heatmap aggregates flags, weakness notes, and Red RAG into one prioritised list.
4
Check subject averages to compare which subjects need most attention relative to their grade boundaries.
tip Visit Analytics weekly. A 5-minute review of your trends is more useful than an hour of unfocused revision.
Notes & Canvas
Write typed notes or draw freehand diagrams — organised by subject and topic, always in sync.
1
Create a collection for each subject or topic. Collections live in the left panel — tap to open.
2
Switch between Text and Canvas mode with the tabs at the top of each note.
3
In Canvas mode, use the pen, highlighter, or eraser. Pinch to zoom on mobile — works like a real notebook.
4
Add images to a note — paste screenshots of mark schemes or diagrams directly in.
tip Use Zen mode (in topbar) for distraction-free writing. Full screen, no navigation, just your notes.
Tools & Settings
A handful of built-in tools make revision more structured. They live in the topbar and drawer.
⏱
Pomodoro timer — structured focus sessions with short and long breaks. Set durations in Settings.
☽
Zen mode — hides all navigation for distraction-free writing or revision. Press Esc to exit.
✦
Background — switch between the starfield and classic dark background in Settings → Background.
☀
Light mode — tap the moon in the topbar to switch to Morning Scholar (warm stone palette).
tip The quotes on the home page are customisable — add your own in Settings → Add Custom Quote.
Data & Sync
Your data syncs automatically when you're signed in. Connect Google Drive for extra backup snapshots.
1
Sign in with Google to sync your data across all devices automatically via Firestore.
2
Connect Google Drive to create manual snapshots and daily auto-backups. Up to 5 snapshots are kept.
3
Export your data as JSON from the Data page — keep a local backup before exams.
4
Use Import to restore from any backup file. Your entire state is preserved.
tip Take a manual Drive snapshot the night before exams. One tap, dated filename, safe forever.
